# @xzy18/material-components

`xzy-materials` 的统一运行时入口，汇总导出组件、Hooks 与工具函数。

```bash
pnpm add @xzy18/material-components antd react react-dom
```

```tsx
import { AntdProvider, Button, clamp, cx, useBoolean } from "@xzy18/material-components";
```

仍可按需安装并使用以下独立包：

- `@xzy18/components`
- `@xzy18/hooks`
- `@xzy18/utils`
